Stage 01 of 05 · Discover
STAGE 01 · TIMELINE: WEEKS 1–2

Discover & Architecture Audit

We map the business problem, bounded domain contexts, and technical constraints before touching a design tool — ending with an enforceable engineering spec, not a slide deck.

Primary Milestone Approved System Spec & RFC
Engineering Lead Principal Architect & Tech Lead
M1.1 Audit & Baseline

Legacy Systems & Codebase Audit

Comprehensive assessment of existing repos, database schema bottlenecks, API payload structures, throughput constraints, and technical debt hotspots.

Artifact: Tech Debt Register · Performance Profiling Baseline
Technical Milestones & DoD
  • Profile p95/p99 endpoint latency baselines under peak synthetic load
  • Catalogue third-party SaaS dependencies & auth token lifecycles
  • Audit relational indexing bloat, locks & connection pool headroom
M1.2 Domain Modeling

Domain Boundary & Event Storming

Collaborative event storming workshops to define core domain aggregates, entity-relationship models, read/write boundaries, and event schemas.

Artifact: Bounded Context Map · Domain Entity Relationship Model
Technical Milestones & DoD
  • Classify DDD aggregate root boundaries & transactional invariant rules
  • Author immutable domain event definitions & async message schema registry
  • Model CQRS read/write access paths with optimistic concurrency checks
M1.3 Infrastructure Spike

Non-Functional Targets & Cloud Spike

Benchmarking latency requirements, TPS throughput goals, HA redundancy models, and cloud provider selection (AWS/GCP/Azure) with estimated run-rate costs.

Artifact: Cloud Topology Spike · Run-Rate Budget Model
Technical Milestones & DoD
  • Verify multi-AZ failover & RTO (<30m) / RPO (<5m) disaster recovery bounds
  • Calibrate sustained throughput targets (5,000+ RPS) under traffic surge spike
  • Produce transparent monthly cloud compute & egress unit cost forecast
M1.4 Sprint Charter

Engineering PRD & Sprint Charter

Codifying technical requirements, velocity baselines, team composition, service-level objectives (SLOs), and the definitive Definition of Done (DoD).

Artifact: Architecture RFC · Sprint 1 Backlog Ready
Technical Milestones & DoD
  • Sign off Architectural Decision Records (ADRs) with stakeholder teams
  • Lock enforceable Service Level Objectives (SLOs) & quarterly error budgets
  • Commit sprint 1 estimation poker, ticket DoD criteria & acceptance tests
Core Tooling & Protocols:
OpenAPI v3 PostgreSQL DDL Miro Event Storming OpenTelemetry AWS/GCP Architecture
Stage Definition of Done:
Target SLOs, latency & throughput modeled Cloud topology & infrastructure budget locked Architecture RFC signed off by client stakeholders
STAGE 02 · TIMELINE: WEEKS 3–5

Design & Systems Architecture

Architecture and interface design run in parallel, establishing strict API contracts, database migration blueprints, security threat models, and tokenized UI components.

Primary Milestone Contract-First Prototype & Schema
Engineering Lead Staff Systems Architect & Product Designer
M2.1 Contract Design

API Contract & Schema Hardening

Authoring typed OpenAPI v3 & gRPC protobuf schemas, async message bus topologies (Kafka/RabbitMQ), and idempotency key specifications.

Artifact: OpenAPI Spec Repo · Mock API Sandbox
Technical Milestones & DoD
  • Publish OpenAPI 3.1 & Protobuf specs with automated TypeScript type generation
  • Deploy mock API sandbox container for seamless frontend/backend parallel tracks
  • Specify UUIDv7 idempotency keys & RFC 7807 problem details payloads
M2.2 Data Architecture

Persistence & Zero-Downtime Migration

Relational schema DDL design, indexing strategies, partition models, database migration seeds, and fallback rollback scripts.

Artifact: Drizzle/Prisma Schema Models · Migration Test Suite
Technical Milestones & DoD
  • Validate expand-and-contract column migrations with backwards compatibility
  • Benchmark B-tree and GIN composite indexes on 10M record seed sets
  • Automate forward/reverse migration rollbacks in CI sandbox test suites
M2.3 Security Modeling

STRIDE Threat Model & Auth Matrix

Threat vector modeling, OAuth 2.0 / OIDC session management, Role-Based Access Control (RBAC) matrix, and encryption key rotation plans.

Artifact: STRIDE Security Audit · RBAC Permission Ruleset
Technical Milestones & DoD
  • Model attack surfaces across Spoofing, Tampering, Repudiation, Info Disclosure
  • Configure OAuth 2.0 PKCE authentication with JWT rotating asymmetric keys
  • Design granular RBAC policy middleware with zero-trust token claims
M2.4 Design System

Tokenized Design System & State Charts

WCAG AA accessible tokenized component library, interactive prototypes, and explicit state charts for loading, error, empty, and offline modes.

Artifact: Figma Component System · Interactive Flow Prototype
Technical Milestones & DoD
  • Build tokenized design tokens (color, spacing, typography, z-index hierarchy)
  • Map explicit state machines for offline, loading, error, and optimistic updates
  • Verify 100% component accessibility adherence (WCAG 2.1 AA keyboard & screen reader)
Core Tooling & Protocols:
Figma Tokens TypeScript Schemas Swagger / Postman Prisma / Drizzle DDL OAuth 2.0 / OIDC
Stage Definition of Done:
All API contracts mocked and validated Database schemas pass zero-downtime test Clickable prototypes verified by product team
